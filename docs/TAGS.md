# 標籤字典

本文件定義標籤分類與命名原則，避免同一概念出現多種寫法。

## 命名原則

- 優先使用台灣市場常用名稱。
- 中文與英文縮寫可並存，但每個概念只選一個標準名稱。
- 不使用斜線合併不同概念，例如不要寫 `PC/NB`，應拆成 `PC`、`筆電`。
- 不把情緒或股價描述當成標籤，例如「飆股」「低估」「很強」。
- 新標籤應簡短、可重複使用，並能被不同股票共享。

## 新增標籤

新增前先搜尋 repository 是否已有近義詞。若新概念有長期重用價值，可加入本文件；若只是單一公司的描述，應寫在 `summary` 或 `theme_relations.reason`，不要硬做成標籤。
